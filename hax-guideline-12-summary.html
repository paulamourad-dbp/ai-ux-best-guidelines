Microsoft HAX Toolkit · Guideline 12 · "Over time"

Remember recent interactions

Keep a short-term memory so people can say "him", "that", or "again", and the AI knows what they mean.

The core idea

Maintain short-term memory and let users make efficient references to it. Carry state between interactions to give a sense of continuity.

Example from the page: someone expects a voice assistant to keep a conversation going, and gets frustrated if it treats every sentence on its own.

The page's example, side by side

No short-term memory
Who called?
Eric H.
Call him back.
Whom should I call?

Each sentence is handled alone, so "him" means nothing.

Remembers recent turns
Who called?
Eric H.
Call him back.
Calling Eric H.…

"Him" resolves to the last person mentioned.

These two conversations are the dialogue given on the page.

Try it: talk to an assistant with (or without) memory

A toy assistant that answers a few follow-ups. Toggle memory on and off and ask the same thing.

Toy script with only a handful of phrases. Not a real language model.

What "recent memory" can include

The page gives one example. These are my own suggestions for what short-term memory might hold.

👤

Who or what was just discussed

So "him", "her", "it" and "that one" work.

🔍

The last request

So "now do the same for Friday" or "make it shorter" works.

⚙️

Current settings

Filters, units or tone chosen a moment ago stay applied.
