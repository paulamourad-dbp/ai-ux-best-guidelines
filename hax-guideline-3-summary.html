Microsoft HAX Toolkit · Guideline 3 · "During interaction"

Time services based on context

Decide when your AI speaks up, based on what the person is doing and where they are.

The core idea

If your AI can start interactions by itself (alerts, suggestions, reminders), think about the user's current task and attention. Should it act now, or wait?

Example from the page: a push alert should probably be postponed while the user is driving.

The recipe

📡 Capture context signals→🧠 Infer a good moment→⏱️ Act, or hold off

Signals can include current task, location, motion, calendar, or attention. Do it in a privacy-aware way, balancing user benefit against privacy.

Watch-outs

Privacy trade-off

Knowing context means collecting signals. Collect only what's needed, and explain why.

Wrong inference

If the system guesses context incorrectly, it may delay something important. Make critical alerts hard to suppress.
