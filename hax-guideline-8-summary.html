Microsoft HAX Toolkit · Guideline 8 · "When wrong"

Support efficient dismissal

If the AI shows up when it isn't wanted, make it easy to wave it away.

The core idea

AI systems will make mistakes. One kind is activating when not needed or expected. So make it easy to dismiss or ignore its services, so people can recover quickly.

Example from the page: a voice assistant should be easy to dismiss if it mistakenly triggers or acts in an inappropriate situation.

Ways to make dismissal easy

The page doesn't give a list. These are common options I'm suggesting.

✕ Close button
Obvious, one click, near the message.
⌨️ Esc key
Quick for keyboard users.
🙅 "No thanks" / "Not now"
Plain-language choice in the prompt.
⏩ Just keep working
Ignoring it is enough; it fades away without blocking.
