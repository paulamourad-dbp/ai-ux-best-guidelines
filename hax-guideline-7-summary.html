Microsoft HAX Toolkit · Guideline 7 · "When wrong"

Support efficient invocation

If the AI doesn't show up when you need it, there should be an easy way to call it in yourself.

The core idea

AI systems will make mistakes. One kind of mistake is not activating when it should (or not as expected). So give people a simple way to manually invoke the AI's services and recover.

Example from the page: a writing assistant that suggests more inclusive phrasing should let the user request suggestions manually, in case it fails to trigger when desired.

The problem, in 3 steps

✍️ User types something that needs help→ 🤖 AI doesn't trigger→ 🔘 Manual "invoke" button saves the day

Without that last step, the user is stuck: the help exists, but they can't reach it.

Try it: auto-trigger vs. manual invoke

A writing assistant looks for non-inclusive phrasing. It sometimes misses. Type something, then see what happens in each design. Try the sample phrases.
