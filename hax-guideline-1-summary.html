Microsoft HAX Toolkit · Guideline 1 · "Initially"

Make clear what the system can do

Before people use an AI, help them understand what it's designed for, and what it isn't.

The core idea

Many AI systems handle several tasks across several domains. If people don't know which, they get disappointed, abandon the product, or even get harmed. So set expectations about what the system is designed for.

The page's example: a fitness tracker

A tracker that counts steps while walking and running might not support everything people assume.

Supported
  • 🚶 Walking steps
  • 🏃 Running steps
Not supported
  • 🚴 Cycling domain mismatch
  • 😴 Sleep quality task mismatch

Domain mismatch = the right task in an unsupported area (steps, but on a bike). Task mismatch = a different task altogether (sleep quality). Both are from the page.

Without vs. with expectation-setting

Unclear
Welcome! Start tracking.
Log my bike ride
Sorry, I can't do that.

Disappointment, and maybe the user leaves.

Clear
Welcome! I track walking and running steps. Cycling and sleep aren't supported yet.
Log my run
Done: 5.2 km, 6,800 steps.

Right expectations from the start.
